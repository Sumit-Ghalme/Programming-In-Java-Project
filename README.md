# Personal Finance Manager

## Description

Personal Finance Manager is a Java web-based application that was built using Java Servlets and JSP technology.

This app enables the users to add income and expenses and check their finances' balance.

## Features

- Income adding
- Expenses adding
- Viewing the list of transactions
- Calculating total income
- Calculating total expenses
- Calculating balance
- Deleting transactions
- User-friendly interface

## Technologies used

- Java
- Jakarta Servlets
- JSP
- HTML
- CSS
- Maven
- Apache Tomcat

## Requirements

- JDK 17 or higher
- Apache Maven
- Apache Tomcat 10.1.x
